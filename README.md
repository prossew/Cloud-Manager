# Cloud Manager

Приложение для управления и мониторинга узлов (frontend + lightweight backend).

## Описание

Cloud Manager предоставляет интерфейс для добавления, управления и мониторинга «узлов» (nodes) в локальной сети или облачной среде. Проект разделён на frontend (клиентское приложение на Vite + React + TypeScript) и простой сервер на Node/TypeScript, который реализует WebSocket-соединение для обмена состоянием.

## Ключевые возможности

- Удобная панель управления узлами: добавление, фильтрация, просмотр деталей
- Визуализация метрик и граф сети
- Терминал/консоль для взаимодействия с узлом (визуально)
- WebSocket-связь с сервером для реального времени

## Технологии

- Frontend: Vite, React, TypeScript, Tailwind (частично), Recharts
- Backend: Node + TypeScript + `ws` (WebSocket)

## Структура проекта (важные папки)

- `src/` — frontend исходники (компоненты, фичи, виджеты)
- `server/` — серверная часть (WebSocket + простая логика)
- `public/` — статические файлы
- `Dockerfile`, `docker-compose.yml` — контейнеризация

## Быстрый старт (локально)

1. Установить зависимости и запустить frontend:

```bash
npm install
npm run dev
```

2. Запустить сервер (в отдельном терминале):

```bash
cd server
npm install
npm run dev
```

Примечание: в корне проекта доступны скрипты из package.json:

- `dev` — запускает Vite для разработки фронтенда
- `build` — билд фронтенда
- `preview` — превью собранного фронтенда

Скрипты сервера (в `server/package.json`):

- `dev` — `tsx watch src/index.ts` (запуск серверной части в режиме наблюдения)

## Запуск через Docker

```bash
docker-compose up --build
```

## Советы по разработке

- Фронтенд использует TypeScript и Vite — при изменениях компонентов перезапуск обычно не требуется.
- Сервер использует `tsx` для быстрого запуска TypeScript-файлов без ручной компиляции.
- Для отладки WebSocket-событий смотрите `server/src/ws.ts` и `server/src/router.ts`.
